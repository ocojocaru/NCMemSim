# NCMemSim visual identity

NCMemSim uses a technical visual language based on multilayer device stacks, nanocrystal charge nodes and directed simulation flow. The identity is intended to remain readable in repositories, documentation, presentations and scientific figures.

## Mark

The square mark represents three dielectric/floating-gate levels connected by a charge-transfer trajectory. It is not a literal band diagram; it is a project symbol.

## Wordmark

Use `assets/logo.svg` when horizontal space is available and `assets/logo-mark.svg` for icons, favicons and square avatars.

## Banner

The project banner states the software name, scientific scope and four implemented pillars: electrostatics, transport, retention and validation.

## Scientific diagrams

The diagrams in `assets/` are deliberately schematic. They explain architecture and data flow without implying dimensions, band offsets or measured device geometry. For publication, captions must state that they are schematics.

## Accessibility

All SVG assets contain titles and descriptions. Text contrast is designed for light and dark presentation contexts. Do not encode scientific meaning through color alone; retain labels and arrows.
