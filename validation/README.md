# Scientific Validation Pack

This directory contains deterministic numerical reference data, benchmark
artifacts, experimental-data placeholders, and supporting material used by the
NCMemSim validation and reproducibility workflows.

The current v0.10.0 validation baseline covers both the established electrical
framework and the Phase E optical-programming extension.

Golden-reference files are compared numerically in the automated test suite and
are intended for regression control. They are not a substitute for experimental
validation of a fabricated device.

Experimental reference datasets should include sufficient provenance,
measurement conditions, units, sample identification, and calibration metadata
to support reproducible comparison with simulation results.

See `../docs/validation.md`, `../docs/Validation_Report.md`, and
`../docs/reproducibility.md` for the current validation and reproducibility
policy.
