# Security policy

## Supported versions

NCMemSim is pre-1.0 research software. Security and correctness fixes are applied to the latest published release and to the `main` development branch.

## Reporting a vulnerability

Do not disclose a suspected security vulnerability in a public issue. Use GitHub private vulnerability reporting when it is enabled for the repository, or contact the repository owner privately through the account listed in `CODEOWNERS`.

Include the affected version, environment, reproduction steps, impact and any proposed mitigation. Scientific-model disagreements, numerical defects and validation questions should use the dedicated issue templates rather than the private security channel.
