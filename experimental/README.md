# Experimental workspace

This directory is reserved for exploratory experimental-data workflows that are
not part of the stable NCMemSim API.

Candidate contents include:

- experimental C-V datasets;
- retention measurements;
- transient program/erase data;
- wavelength-dependent or optical-programming measurements;
- prototype loaders;
- fitting experiments;
- calibration notebooks or scripts.

Code and data placed here may be incomplete, provisional, or incompatible with
the current release.

Promotion of functionality from `experimental/` into the stable `ncmemsim/`
package requires documented physical scope, parameter provenance, tests,
reproducibility support, and compatibility review.

Do not place confidential or unpublished experimental data in the public
repository unless their release has been explicitly approved.
