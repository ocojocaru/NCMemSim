# Documentation inventory and release-context audit

Reviewed against published v1.10.0 on 2026-11-05. The [platform status](platform_status.md)
is the current capability/release map. This inventory covers every documentation
Markdown page; it is not a claim of new experimental qualification or a new audit
of every physical equation. Technical examples retain their original meaning.

## Changes and preservation rules

- Correct global absence claims for sequential optics, compact TAT/image-force
  corrections, structural diagnostics and implemented release stages.
- Distinguish unchanged default paths from explicit opt-in extensions.
- Consolidate S0-S7 into delivered v1.10 scope; keep remaining research separate.
- Mark historical contracts/checklists/evidence with their original version scope.
- Preserve generated API inventory and exact-render stable API manifest, machine-readable approved reviews, source-pinned
  measurement data, fixtures, original release tags/assets and runtime source.
- Root README/VISION/CONTRIBUTING are maintained entry points. CHANGELOG is a
  chronological record. Root RELEASE_CHECKLIST, RELEASE_VERIFICATION and
  FIRST_GITHUB_RELEASE already identify themselves as historical v0.9.1 records.
  Branding and conduct policies retain their separate scope. SECURITY.md now
  identifies stable 1.x research software while retaining the existing reporting
  channel and latest-release/main maintenance policy.
